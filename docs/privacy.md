# TypeTrek 隐私说明

> 本文档面向使用者，说明程序**采集什么、存到哪里、如何删除**。
> 程序定位为个人效率统计工具，不提供任何隐蔽运行或对抗检测的能力。

## 一、数据采集范围

### 采集

| 数据 | 字段 | 用途 |
|------|------|------|
| 键盘按下/释放 | 时间戳、键位标识（`KeyA`/`Space`/`ShiftLeft`…）、是否自动重复、前台应用 | 键盘热力图、Top 键位、活跃趋势 |
| 鼠标按下 | 时间戳、按钮（left/right/middle/x1/x2）、屏幕坐标（虚拟桌面物理像素）、显示器、前台应用 | 点击热力图、按钮分布、Top 区域 |
| 显示器快照 | 设备标识、分辨率、DPI 缩放、虚拟桌面坐标 | 热力图布局重建 |
| 前台应用 | 进程可执行文件名（如 `chrome.exe`） | 按应用统计、黑名单判定 |

### 明确不采集

- **输入内容**：不做字符映射、不做按键序列合成、不记录剪贴板。数据库中的键盘记录是"键位标识 + 时间戳"，程序**没有**任何将其还原为文本的功能。
- **窗口标题**：代码中不存在 `GetWindowTextW` 调用路径。
- **鼠标移动轨迹与滚轮**：钩子层直接忽略。
- **屏幕截图、音频、摄像头**：与本程序无关。
- **网络传输**：程序不包含任何 HTTP/网络代码，构建配置未授予网络权限；可在断网环境下完整运行。

## 二、数据存储

- 位置：`%APPDATA%\com.dengqn.app.typetrek\`
  - `typetrek.db`：SQLite 数据库（WAL 模式）
  - `settings.json`：设置与同意状态
- 权限：Windows 用户目录 ACL，默认仅当前用户可读。
- 分层：
  - **明细**（`key_events` / `mouse_events`）：受保留期管理，默认 90 天后自动清理。
  - **聚合**（按日/小时/应用/网格的计数）：永久保留，是热力图与日历的数据源；不含时间序列。
  - **字典**（应用名 / 显示器 / 会话）：保留以解释历史数据。
- 加密：设置页可开启 SQLCipher 整库加密，256-bit 密钥存入 Windows 凭据管理器（不落磁盘明文）。
  加密**只对新建数据库生效**：明文库与加密库之间切换需先导出数据并清空数据库文件
  （工具刻意不提供在线迁移——迁移失败会导致数据不可读，风险大于收益）。

## 三、隐私控制手段

| 手段 | 效果 | 位置 |
|------|------|------|
| 首启知情同意 | 未同意时不创建采集线程 | 首次启动页面 |
| 暂停采集 | 事件在钩子回调最前端丢弃（不入队） | 托盘菜单 / 主界面 / `Ctrl+Alt+P` |
| 键盘、鼠标分开关 | 单独停用某一类采集 | 设置页 |
| 敏感应用黑名单 | 名单应用的事件**在写入前丢弃**，应用名也不进入字典 | 设置页 |
| 隐私模式 | 明细完全不落盘，仅保留聚合计数 | 设置页 |
| 保留期 | 明细到期自动清理（30/90/180/365 天） | 设置页 |
| 按日期删除 | 删除指定区间的明细与聚合（不可恢复） | 数据管理页 |
| 导出确认 | 导出明细前二次确认（导出文件为未加密文件） | 数据管理页 |
| 一键定位数据 | 打开数据目录，便于自行检查或彻底删除 | 设置页 / 数据管理页 |

## 四、残余风险（诚实披露）

1. **明细表在保留期内含按键时间序列**：虽然不含输入内容，理论上可被用于行为分析（例如推测输入节奏）。若你需要消除这一风险，请开启**隐私模式**并/或缩短保留期，或定期在数据管理页删除明细。
2. **导出文件不受保护**：导出为明文 CSV/JSON，请自行保管或加密后再传输。
3. **同机其他进程**：若系统已被恶意软件控制，任何本地文件都可能被读取——这超出本程序能防御的范围。
4. **进程名可推断使用行为**：`apps` 字典记录了 exe 名。黑名单可避免敏感应用进入字典，但已记录的历史需要手动删除。

## 五、彻底删除

1. 数据管理页：选择全部日期区间 → 删除；
2. 或直接删除目录 `%APPDATA%\com.dengqn.app.typetrek\`（程序退出状态下操作）；
3. 如启用过开机自启，请在设置页关闭（或删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 TypeTrek 项）；
4. 卸载程序不会自动删除该目录（避免误删你尚未导出的数据），需要你手动清理。

## 六、合规提示

- 仅在你本人拥有或**已获得明确授权**的设备上使用。
- 不得用于监控他人（包括家庭成员、员工）——许多司法辖区将此视为违法行为。
- 若设备属于公司/学校，请先确认组织政策允许安装此类工具。
- 本程序不隐藏自身：托盘图标常驻、暂停状态可见、窗口关闭时提示仍在采集。
