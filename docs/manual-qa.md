# TypeTrek 手动验收清单（T26）

> 自动化测试覆盖纯逻辑与数据层（`cargo test` 81 项、`pnpm test` 28 项）。
> 下列项目依赖真实系统行为（全局钩子、多显示器、托盘、UAC），必须在真机手动执行。
> 建议每次发版前完整过一遍，结果记录在最后。

## 1. 采集正确性

- [ ] **键盘计数核对**：暂停采集 → 用记事本敲 100 次 A → 恢复采集 → 重新敲 100 次 A → 键盘页"今日"显示 KeyA ≈ 100（±5 允许漏掉切换瞬间）。
- [ ] **repeat 口径**：长按空格 3 秒（约 30 次自动重复）→ 关闭"计入自动重复"时应只 +1；开启后应 +30 左右。
- [ ] **中文输入法**：切换到中文输入法打字，热力图应统计到字母键与数字选字键（IME 组合期间按键仍上报）。
- [ ] **鼠标五按钮**：左/右/中/侧键各点 10 次 → 鼠标页按钮分布应各 ≈ 10。
- [ ] **滚轮与移动不采集**：滚动 100 次、大幅移动鼠标 → 点击总数不变（鼠标只记按下）。
- [ ] **注入过滤**：用 AutoHotkey 发送按键（若可用）→ 默认设置下不计入；关闭"过滤脚本注入"后计入。

## 2. 暂停 / 退出 / 托盘

- [ ] 托盘菜单"暂停采集"→ 主界面状态标签变"已暂停"、`按键数` 不再增长；"恢复采集"后恢复。
- [ ] 快捷键 Ctrl+Alt+P（或自定义）切换暂停/恢复，托盘 tooltip 同步变化。
- [ ] 点击主窗口关闭按钮 → 窗口隐藏，**首次**出现"仍在采集中"通知；再次关闭不再提示。
- [ ] 托盘左键单击 → 主窗口显示并置顶。
- [ ] 托盘"退出 TypeTrek"→ 进程结束；重新打开后数据连续，`sessions` 表新增一条且有 `ended_at`。
- [ ] 任务管理器强杀进程 → 重启后应用正常、无数据库损坏错误（WAL 容错）。

## 3. 多显示器与 DPI

- [ ] 双屏（含主屏在右侧、副屏负坐标）分别在两屏点击 20 个已知位置 → 热力图亮区与实际位置一致。
- [ ] 两屏 DPI 缩放不同（如 100% / 150%）→ 光点位置仍对齐（不会整体偏移或缩小）。
- [ ] 热插拔显示器 / 修改分辨率 → 30 秒内布局更新；旧数据仍渲染在原位置（历史快照）。
- [ ] 单屏查看模式下只显示该屏数据。

## 4. 敏感应用黑名单

- [ ] 打开密码管理器（如 KeePassXC），在其中按键 1 分钟、点击 20 次 → 该时段按键/点击统计无增长。
- [ ] 该应用不出现在设置页"从最近应用添加"的列表中（apps 字典未写入）。
- [ ] 通配符：添加 `*bank*` 后，名称含 bank 的进程行为一致被排除。
- [ ] 移除黑名单后恢复记录。

## 5. 隐私模式与保留期

- [ ] 开启隐私模式 → 正常使用 5 分钟 → 数据管理页"按键明细/点击明细"行数不增长，而概览/热力图数字继续增长。
- [ ] 关闭隐私模式 → 明细恢复写入。
- [ ] 将保留期设为 30 天 → "立即清理过期明细"提示删除数量符合预期；聚合数据不减少（概览数字不变）。
- [ ] 按日期删除今天的数据 → 概览/热力图/日历今日全部归零，其他日期不受影响。

## 6. 导出

- [ ] CSV（统计聚合）导出 → Excel 打开中文表头正常、行数与数据管理页统计相符。
- [ ] CSV（明细）导出 → 弹出二次确认；确认后文件含 `ts,time,kind,...` 列；含逗号/引号的键码转义正确。
- [ ] JSON（聚合 / 明细）导出 → `jq .` 可解析（注意：文件前部为头部对象 + 正文对象两段，`jq -s` 可合并解析）。
- [ ] 导出对话框取消 → 无文件产生、无错误提示。

## 7. 首启与设置

- [ ] 删除 `%APPDATA%\com.dengqn.app.typetrek\settings.json` → 重启进入首启同意页；此时任务管理器观察：无钩子线程（未同意不采集）。
- [ ] 点"暂不同意（仅浏览界面）"→ 进入设置页，状态显示"未授权采集"，热力图无数据。
- [ ] 在设置页重新授权路径：需删除 settings.json 重启（无独立授权按钮，属已知限制）。
- [ ] 开机自启开关 → 注册表 `HKCU\...\Run` 出现/移除 TypeTrek 项。
- [ ] 更改快捷键后旧快捷键失效、新快捷键生效。
- [ ] 修改窗口标题采集？—— 无此开关（设计如此）。

## 8. 平台限制（预期行为，非缺陷）

- [ ] UAC 提权的窗口（如"以管理员身份运行"的任务管理器）中按键/点击**不被记录**（UIPI 限制，预期）。
- [ ] 锁屏 / 快速用户切换期间无数据，解锁后恢复。
- [ ] 杀毒软件/SmartScreen 首次运行提示；选择"仍要运行"后正常（未签名应用的预期提示）。

## 9. 性能与资源

- [ ] 挂机采集 1 小时：任务管理器 CPU 平均 < 1%、内存 < 150MB（含 WebView2）。
- [ ] `cargo run --release --bin bench_events -- 30 10000`：丢弃率 < 0.1%、写入错误 0。
- [ ] 30 天范围切页/切范围响应 < 500ms。
